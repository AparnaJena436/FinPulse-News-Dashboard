# FinPulse News – Financial News & Market Sentiment Dashboard

A financial news dashboard that brings Indian and global financial news together and provides a simple overview of market sentiment.

## Features :

* Indian & global financial news
* India market sentiment tracker
* Global market sentiment tracker
* Bullish / Bearish / Neutral classification
* Interactive dashboard

## How It Works

Financial news is collected through RSS feeds and analyzed using a rule-based approach based on positive and negative financial keywords. The results are used to generate India and Global sentiment indicators.

## Built With

HTML • CSS • JavaScript • RSS Feeds • RSS2JSON
